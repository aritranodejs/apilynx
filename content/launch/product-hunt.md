## Full description

### What is Apilynx?

Apilynx is a modern API client built for developers who want Postman-style workflows without the bloat. Send REST and GraphQL requests, manage collections and environments, run tests, generate code, mock APIs, and export documentation — all from a fast desktop app or your browser.

### Why we built it

Most API clients either lock you into a cloud account before you can send a GET request, or they split GraphQL, load testing, and docs across different tools. Apilynx puts the essentials in one place and stays free for core testing.

### Key features

- **REST + GraphQL** — One request builder for HTTP and GraphQL (query + variables).
- **Desktop + browser** — Download for Windows, macOS, and Linux, or open `/app` with zero install.
- **No signup wall** — Send requests in the browser without creating an account.
- **Collections & environments** — Workspaces, `{{variables}}`, and JSON export.
- **Tests & collection runner** — Smoke your APIs before you ship.
- **Load testing** — Concurrent requests with success/failure stats in-app.
- **Mock server** — Stub endpoints for frontend and integration work.
- **Docs & code gen** — HTML docs and snippets (cURL, fetch, axios, etc.).
- **MIT licensed** — Open source. Inspect, fork, contribute.

### Who is it for?

- Solo developers and startups who want a lightweight alternative to Postman.
- Teams evaluating API clients (we publish honest comparisons vs Postman, Insomnia, Bruno, and more).
- Anyone who needs browser-based API testing without CORS workarounds on desktop.

### How is it different from Postman?

Apilynx focuses on the daily workflow — send, organize, test, document — without requiring a cloud workspace to get started. Load tests and mocks are built in. Core testing stays free. See our blog: **Why Apilynx vs Postman** in the docs.

Free for core API testing. MIT license.
